## 新增需求

### 需求：通过配置流程设置安装范围
配置档案 workflow 程应允许用户配置安装范围偏好。

#### 场景：交互式配置包含安装范围
- **WHEN** 用户运行 `openspec config profile`
- **THEN** 交互式流程应包含安装范围选择，可选值为 `global` 和 `project`
- **AND** 当前配置的值应被预选中

#### 场景：保存安装范围
- **WHEN** 用户确认配置档案变更
- **THEN** 选中的安装范围应保存到全局配置

### 需求：配置输出中显示安装范围
config 命令应在人类可读的输出中显示安装范围偏好。

#### 场景：配置列表显示安装范围
- **WHEN** 用户运行 `openspec config list`
- **THEN** 输出应包含当前的安装范围值
- **AND** 指示该值是默认值还是显式设置的值
