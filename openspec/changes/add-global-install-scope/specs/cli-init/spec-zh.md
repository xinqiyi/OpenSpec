## 新增需求

### 需求：Init 安装作用域选择
init 命令应为生成的制品支持安装作用域选择。

#### 场景：作用域默认为全局
- **当** 用户运行 `openspec init` 且未显式指定作用域
- **则** init 应使用全局配置的安装作用域
- **且** 如果未设置，应解析为迁移感知默认值（新创建配置为 `global`，旧版模式演化配置为 `project`）

#### 场景：通过标志覆盖作用域
- **当** 用户运行 `openspec init --scope project`
- **则** init 应为该次运行使用 `project` 作为首选作用域
- **且** 除非用户显式更改配置，否则不应修改持久化的全局配置

### 需求：Init 使用有效作用域解析
init 命令应在生成文件之前为每个工具表面解析有效作用域。

#### 场景：带回退的有效作用域
- **当** 所选工具/表面不支持首选作用域
- **且** 支持备选作用域
- **则** init 应在备选有效作用域生成文件
- **且** 应在摘要中显示回退说明

#### 场景：不支持的作用域选择
- **当** 所选工具/表面既不支持首选也不支持备选作用域
- **则** init 应在写入文件之前失败
- **且** 应提供清晰的错误指导
