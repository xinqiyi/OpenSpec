## 新增需求

### 需求：Update 安装作用域选择
update 命令应为同步操作支持安装作用域选择。

#### 场景：作用域默认为全局配置值
- **当** 用户运行 `openspec update` 且未显式指定作用域
- **则** update 应使用配置的安装作用域
- **且** 如果未设置，应解析为迁移感知默认值（新创建配置为 `global`，旧版模式演化配置为 `project`）

#### 场景：通过标志覆盖作用域
- **当** 用户运行 `openspec update --scope project`
- **则** update 应为该次运行使用 `project` 作为首选作用域

### 需求：作用域感知同步和漂移检测
update 命令应使用有效作用域路径评估配置状态和漂移。

#### 场景：作用域感知漂移检测
- **当** update 评估工具是否最新时
- **则** 它应检查每个工具/表面在有效作用域目标处的文件
- **且** 应将当前解析的作用域与每个工具/表面最后成功的有效作用域进行比较
- **且** 应将差异视为需要同步的漂移

#### 场景：Update 期间的作用域回退
- **当** 首选作用域不受已配置的工具/表面支持
- **且** 备选作用域受支持
- **则** update 应应用回退作用域解析
- **且** 应在输出中报告回退

#### 场景：Update 期间不支持的作用域
- **当** 已配置的工具/表面既不支持首选也不支持备选作用域
- **则** 应在任何写入操作之前对所有已配置的工具/表面进行作用域支持验证
- **且** 当检测到不兼容时，update 应失败而不执行文件写入
- **且** 应报告不兼容的工具及修复步骤
