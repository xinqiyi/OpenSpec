## 修改的需求

### 需求：ToolCommandAdapter 接口
系统应提供安装上下文感知的命令路径解析。

#### 场景：适配器接口结构
- **WHEN** 实现工具适配器时
- **THEN** 命令文件路径解析应接收安装上下文（包括有效作用域和环境上下文）
- **AND** 应返回该上下文的有效命令输出路径

#### 场景：Codex 全局路径继续保持支持
- **WHEN** 在全局作用域中解析 Codex 命令路径时
- **THEN** 适配器应在设置了 `CODEX_HOME` 时指向 `$CODEX_HOME/prompts`
- **AND** 否则应指向 `~/.codex/prompts`

### 需求：命令生成器函数
命令生成器应将安装上下文传递到所有生成命令的适配器路径解析中。

#### 场景：作用域感知命令生成
- **WHEN** 为具有已解析有效作用域的工具生成命令时
- **THEN** 生成的命令路径应匹配该有效作用域
- **AND** 格式化的命令正文/前置元数据行为应保持特定于工具且不变
