# 向 OpenSpec CLI 添加 List 命令

## 为什么

开发人员需要了解可用变更及其状态，以理解项目的演变和待处理工作。

## 变更内容

- 添加 `openspec list` 命令，显示 changes/ 目录中的所有变更
- 显示每个变更名称及任务完成计数（例如，"add-auth: 3/5 任务"）
- 显示完成状态指示器（完全完成显示勾号，部分完成显示进度）
- 跳过 archive/ 子目录以聚焦活跃变更
- 简单表格输出，便于快速浏览

## 影响

- 受影响的规范：将新增 `cli-list` 能力
- 受影响的代码：
  - `src/cli/index.ts` - 添加 list 命令
  - `src/core/list.ts` - 包含目录扫描和任务解析的新文件（约 60 行）
