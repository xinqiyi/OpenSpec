# CLI Diff 命令 - 变更

## 移除的需求

### 需求：显示格式

diff 命令应以文本格式显示统一的 diff 输出。

**移除原因**：标准的统一 diff 格式被需求级并排比较取代，后者能更好地显示语义变更，而非逐行的文本差异。

#### 场景：统一 diff 输出（已弃用）

- **WHEN** 运行 `openspec diff <change>`
- **THEN** 显示文件的统一文本 diff
- **AND** 包含以 `+`/`-` 前缀的行，表示添加和删除

## 修改后的需求

### 需求：Diff 输出

命令应显示需求级比较，仅显示已更改的需求。

#### 场景：变更的并排比较

- **WHEN** 运行 `openspec diff <change>`
- **THEN** 仅显示已更改的需求
- **AND** 以并排格式显示：
 - 左侧清晰显示当前版本
 - 右侧显示未来版本
 - 指示新增需求（当前版本中没有）
 - 指示移除的需求（未来版本中没有）
 - 对齐修改的需求以便于比较

## 新增需求

### 需求：验证

命令应验证变更可以成功应用。

#### 场景：无效的 delta 引用

- **WHEN** delta 引用了不存在的需求
- **THEN** 显示带有具体需求的错误消息
- **AND** 继续显示其他有效变更
- **AND** 在输出中清晰标记失败的变更
