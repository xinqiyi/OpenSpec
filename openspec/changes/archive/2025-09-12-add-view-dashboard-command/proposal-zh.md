# 变更：添加 View 仪表板命令

## 为什么

用户需要一个快速、一目了然的 OpenSpec 项目状态概览，而无需运行多个命令。目前，用户必须分别运行 `openspec list --changes` 和 `openspec list --specs` 来了解项目状态。统一的仪表板视图将改善开发者体验，并提供对项目进度的即时洞察。

## 变更内容

### 新增 `openspec view` 命令

新命令提供一个交互式仪表板，显示：
- 摘要指标（总规范数、需求数、变更数、任务进度）
- 带有可视化进度条的活跃变更
- 已完成的变更
- 带有需求数量的规范

### 受影响的规范

- **cli-view**（新建）：view 仪表板命令的完整规范

## 实现细节

### 文件结构
- 创建 `/src/core/view.ts` 实现 `ViewCommand` 类
- 在 `/src/cli/index.ts` 中注册命令
- 复用 `task-progress.ts` 和 `MarkdownParser` 中的现有工具

### 视觉设计
- 使用 Unicode 框绘图字符作为边框
- 颜色编码：青色用于规范，黄色用于活跃，绿色用于已完成
- 使用填充（`█`）和空（`░`）块的进度条
- 带有适当填充的整洁对齐

### 技术方法
- 从变更和规范目录异步获取数据
- 规范和变更的并行处理
- 缺失或无效数据的错误处理
- 与现有 list 命令输出保持一致
