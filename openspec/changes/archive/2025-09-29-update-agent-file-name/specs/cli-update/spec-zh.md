## 修改后的需求

### 需求：更新行为
更新命令应以团队友好的方式将 OpenSpec 指令文件更新为最新模板。

#### 场景：运行更新命令
- **当** 用户运行 `openspec update`
- **则** 将 `openspec/AGENTS.md` 替换为最新模板

### 需求：文件处理
更新命令应以可预测且安全的方式处理文件更新。

#### 场景：更新文件
- **当** 更新文件时
- **则** 将 `openspec/AGENTS.md` 完全替换为最新模板

### 需求：核心文件始终更新
更新命令应始终更新 OpenSpec 核心文件，并显示 ASCII 安全成功消息。

#### 场景：更新成功
- **当** 更新成功完成时
- **则** 将 `openspec/AGENTS.md` 替换为最新模板
