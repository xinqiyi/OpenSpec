# 设计：代理指令更新

## 方案

### 信息架构
- **前置关键信息** - 三阶段工作流放在首位
- **清晰层级** - 核心工作流 → 快速入门 → 命令 → 详情 → 边界情况
- **长度减少 50%** - 目标从当前约 575 行减少到约 285 行
- **祈使语气** - "创建提案"而非"你应该创建一个提案"
- **要点优先于段落** - 可快速浏览的简洁信息

### 三阶段工作流文档
工作流现在作为核心概念突出展示：
1. **创建** - 提案生成阶段
2. **实施** - 代码开发阶段，包含明确的步骤：
   - 阅读 proposal.md 以理解内容
   - 阅读 design.md 以获取技术背景
   - 阅读 tasks.md 以获取检查清单
   - 按顺序实施任务
   - 每完成一个任务立即标记完成
3. **归档** - 部署后的收尾阶段

这种结构帮助代理理解生命周期及其在每个阶段的角色。实施阶段特别详细，以防止常见错误，如跳过文档或批量标记任务完成。

### CLI 文档更新
- **全面的命令覆盖** - 记录了所有 9 个主要命令
- **`openspec list` 突出展示** - 对于发现变更和规范至关重要
- **交互模式文档** - 代理如何有效使用提示
- **完整标志文档** - 所有选项，如 --json、--type、--skip-specs
- **弃用清理** - 移除名词优先模式（openspec change show）

### 代理特定增强
基于编码代理（Claude Code、Cursor 等）的行业最佳实践：

**实施工作流**
- 明确步骤防止跳过关键上下文
- 先阅读 proposal/design 确保编码前理解充分
- 顺序完成任务保持专注
- 立即标记防止丢失进度跟踪
- 解决常见失败模式：直接跳入编码

**规范发现工作流**
- 创建新规范前始终检查现有规范
- 使用 `openspec list --specs` 发现现有能力
- 优先修改现有规范而非创建重复规范
- 防止碎片化，维护一致的架构

**决策清晰度**
- 清晰的决策树消除模糊条件
- 每个决策分支的具体示例
- 简化的缺陷与功能判断

**工具使用指南**
- 工具选择矩阵（何时使用 Grep vs Glob vs Read）
- 常见失败的错误恢复模式
- 确认正确性的验证工作流

**上下文管理**
- "执行任何任务之前"检查清单用于收集上下文
- 开始任何工作前应阅读的内容
- 如何在交互间维护状态

**规范文件结构文档**
- 包含 ADDED/MODIFIED/REMOVED 部分的完整示例
- 关键的场景格式（#### Scenario: 标题）
- 差异文件位置清晰说明（changes/{name}/specs/）
- 解决回顾中发现的最常见创建错误

**故障排查和调试**
- 常见错误信息及解决方案
- 差异检测调试步骤
- 验证最佳实践
- 用于检查的 JSON 输出
- 防止因静默失败导致的数小时困扰

**最佳实践**
- 简洁（适当时使用一行回答）
- 具体（file.ts:42 行引用）
- 从简单开始（少于 100 行，单文件默认）
- 证明复杂性（需要指标/数据）

## 设计理由

### 为什么这些变更重要

**认知负荷减少**
- 代理在清晰结构下能更好地处理指令
- 前置关键信息减少扫描时间
- 决策树消除分析瘫痪

**行业对齐**
- 遵循在 Claude Code、Cursor、GitHub Copilot 中已验证有效的模式
- 解决常见失败模式（模糊决策、缺少上下文）
- 针对 LLM 优势（模式匹配）而非劣势（计算）进行优化

**解决关键痛点（来自回顾）**
- **场景格式** - 最大难点，现已通过示例明确记录
- **完整规范结构** - 完整示例防止结构错误
- **差异检测问题** - 调试命令帮助诊断问题
- **静默解析失败** - 故障排查部分解释常见问题

**实际影响**
- 更快的代理理解任务
- 更少的需求误解
- 更一致的实施质量
- 出现问题时更好的错误恢复
- 防止用户体验中发现的最常见错误

## 权衡

### 我们移除的内容
- 可推断概念的冗长解释
- 未增加清晰度的冗余示例
- 冗长的边界情况文档（移至参考部分）
- 已弃用的命令文档

### 我们保留的内容
- 所有关键工作流步骤
- 完整的 CLI 命令参考
- 复杂性管理原则
- 目录结构可视化
- 快速参考摘要

## 实施说明

CLAUDE.md 模板有意比 README.md 更简洁，因为：
- 它出现在每个项目根目录
- 代理可以参考完整的 README.md 获取详情
- 它需要在 AI 上下文窗口中快速加载
- 重点是可立即执行的指导性内容
