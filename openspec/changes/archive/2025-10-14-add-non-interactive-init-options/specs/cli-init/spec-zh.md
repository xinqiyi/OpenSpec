# CLI Init spec delta

## 新增需求
### 需求：非交互式 schema
命令应通过命令行选项支持非交互式操作，用于自动化和 CI/CD 场景。

#### 场景：以非交互方式选择所有工具
- **WHEN** 使用 `--tools all` 运行时
- **THEN** 自动选择每个可用 AI 工具而无需提示
- **AND** 使用所选工具继续初始化

#### 场景：以非交互方式选择特定工具
- **WHEN** 使用 `--tools claude,cursor` 运行时
- **THEN** 解析逗号分隔的工具 ID 并针对可用工具进行验证
- **AND** 仅使用指定的有效工具继续初始化

#### 场景：以非交互方式跳过工具配置
- **WHEN** 使用 `--tools none` 运行时
- **THEN** 完全跳过 AI 工具配置
- **AND** 仅创建 OpenSpec 目录结构和 template 文件

#### 场景：无效的工具 spec
- **WHEN** 使用包含 AI 工具注册表中不存在的 ID 的 `--tools` 运行时
- **THEN** 以退出码 1 退出，并显示可用值（`all`、`none` 或受支持的工具 ID）

#### 场景：帮助文本列出可用工具 ID
- **WHEN** 显示 `openspec init` 的 CLI 帮助时
- **THEN** 显示 `--tools` 选项描述，其中包含从 AI 工具注册表派生的有效值

## 修改后的需求
### 需求：交互式 schema
命令应提供用于 AI 工具选择的交互式菜单，配有清晰的导航说明。

#### 场景：显示交互式菜单
- **WHEN** 在没有非交互式选项的情况下以全新或扩展 schema 运行时
- **THEN** 呈现一个循环选择菜单，让用户使用 Enter 键切换工具，并通过"完成"选项结束
- **AND** 将已配置的工具标记为"（已配置）"，同时保持禁用选项标记为"即将推出"
- **AND** 在扩展 schema 下将提示文本更改为"您想要添加或刷新哪些 AI 工具？"
- **AND** 显示内联说明，澄清 Enter 键切换工具，选择"完成"确认列表
