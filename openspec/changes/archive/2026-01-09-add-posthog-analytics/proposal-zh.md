## 原因

OpenSpec 目前无法了解该工具的使用情况。没有分析数据，我们就无法：
- 了解哪些命令和功能对用户最有价值
- 衡量采用情况和使用 schema
- 做出数据驱动的产品开发决策

添加 PostHog 分析功能可以在尊重用户隐私的同时获取产品洞察，通过透明、可退出的遥测实现。

## 变更内容

- 添加 PostHog Node.js SDK 作为依赖
- 实现带有环境变量退出选项的遥测系统
- 跟踪命令使用情况（仅命令名称和版本）
- 显示首次运行通知，告知用户关于遥测的信息
- 在全局配置中存储匿名 ID（`~/.config/openspec/config.json`）
- 尊重 `DO_NOT_TRACK` 和 `OPENSPEC_TELEMETRY=0` 环境变量
- 在 CI 环境中自动禁用

## 能力

### 新能力

- `telemetry`：使用 PostHog 的匿名使用分析。涵盖命令跟踪、退出控制和首次运行披露通知。

### 修改的能力

- `global-config`：添加遥测状态存储（匿名 ID、通知已见标志）

## 影响

- **依赖**：添加 `posthog-node` 包
- **隐私**：通过环境变量退出，不收集个人数据，清晰披露
- **配置**：用于遥测状态的新的全局配置字段
- **网络**：异步事件发送，退出时刷新（增加约 100-300 毫秒）
- **CI/CD**：当 `CI=true` 时遥测自动禁用
- **文档**：更新 README，添加遥测披露
