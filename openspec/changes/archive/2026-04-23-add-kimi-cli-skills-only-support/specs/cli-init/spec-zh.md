# cli-init 增量规范

## 修改后的需求

### 需求：斜杠命令生成

命令应仅为具有已注册命令适配器的选定工具生成 opsx 斜杠命令，同时保持无适配器工具对技能生成有效。

#### 场景：为具有已注册适配器的工具生成斜杠命令

- **当** 在初始化期间选择了具有已注册命令适配器的工具
- **则** 使用该工具的命令适配器创建 9 个斜杠命令文件：
  - `/opsx:explore`
  - `/opsx:new`
  - `/opsx:continue`
  - `/opsx:apply`
  - `/opsx:ff`
  - `/opsx:verify`
  - `/opsx:sync`
  - `/opsx:archive`
  - `/opsx:bulk-archive`
- **并且** 使用工具特定的路径约定（例如，Claude 使用 `.claude/commands/opsx/`）
- **并且** 包含工具特定的 frontmatter 格式

#### 场景：选定工具没有命令适配器

- **给定** 选定工具配置了 `skillsDir` 但没有已注册的命令适配器
- **当** 初始化包含命令生成时
- **则** 该工具的技能生成仍应保持有效
- **并且** 应跳过该工具的命令文件生成
- **并且** 命令输出应包含 `已跳过命令：<tool-id>（无适配器）`

#### 场景：Kimi CLI 跳过命令文件生成

- **当** 用户在初始化期间选择 Kimi CLI
- **则** OpenSpec 应将其视为带有 `skillsDir: '.kimi'` 的受支持工具
- **并且** 命令文件生成应被跳过，因为没有注册 Kimi 适配器
