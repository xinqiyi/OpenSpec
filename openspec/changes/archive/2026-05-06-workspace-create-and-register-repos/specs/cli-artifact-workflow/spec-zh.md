## 新增需求

### 需求：工作区设置命令
CLI 工件工作流应在创建变更之前提供工作区设置命令。

#### 场景：在变更前准备工作区规划
- **当** 用户需要跨仓库或文件夹准备工作区规划时
- **则** CLI 应提供用于设置、列出、链接、重新链接和诊断工作区的命令
- **并且** 这些命令不应要求有活动的工作区变更

#### 场景：使用简短命令列出工作区
- **当** 用户需要简洁的工作区列表命令时
- **则** CLI 应支持 `openspec workspace ls`
- **并且** 其行为应与 `openspec workspace list` 相同

#### 场景：将设置与代理启动分离
- **当** 用户完成工作区设置时
- **则** 设置工作流应将代理启动和工作区打开行为留给后续工作流
- **并且** 设置不应要求首选代理选择

#### 场景：避免公开直接创建
- **当** 用户在首次工作区设置流程中创建工作区时
- **则** CLI 应使用 `openspec workspace setup`
- **并且** 不应将 `openspec workspace create` 暴露为公开创建路径
