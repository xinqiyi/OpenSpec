## 新增的需求

### 需求：工作区设置安装代理技能
OpenSpec 应允许用户在工作区设置期间将 OpenSpec 代理技能安装到工作区中。

#### 场景：提示选择工作区代理技能
- **当** 交互式工作区设置到达代理技能安装步骤
- **则** OpenSpec 应询问哪些代理应在此工作区获得 OpenSpec 技能
- **且** 提示应使用代理技能语言而非"AI 工具"语言

#### 场景：预选首选开启器
- **给定** 用户选择了支持 OpenSpec 技能生成的首选开启器
- **当** 交互式工作区设置询问哪些代理应获得技能
- **则** OpenSpec 应预选匹配的代理
- **且** 用户应能够选择其他代理或取消选择预选的代理

#### 场景：安装选中的工作区技能
- **当** 工作区设置完成且选中了一个或多个代理
- **则** OpenSpec 应为每个选中的代理在工作区根目录生成或刷新 OpenSpec 技能文件
- **且** 它应报告哪些代理获得了技能
- **且** 它应将选中的代理存储在工作区本地机器状态中

#### 场景：安装 profile 选择的工作流
- **给定** 全局配置解析为工作流 profile
- **当** 工作区设置安装代理技能
- **则** OpenSpec 应为该 profile 选择的工作流安装工作区本地技能
- **且** 它应将 `--tools` 视为代理选择，而非工作流选择
- **且** 它应记录最后应用的工作流 ID 用于漂移检测

#### 场景：设置期间仅安装技能
- **当** 工作区设置安装代理技能
- **则** OpenSpec 应仅生成技能文件
- **且** 它不应生成斜杠命令文件或全局命令文件作为工作区设置的一部分

#### 场景：工作区设置忽略命令交付
- **给定** 全局配置交付为 `commands` 或 `both`
- **当** 工作区设置安装代理技能
- **则** OpenSpec 仍应仅生成工作区本地技能
- **且** 它应报告工作区命令生成不是此切片的一部分

#### 场景：在技能安装期间保留链接的仓库
- **当** 工作区设置安装代理技能
- **则** OpenSpec 应保持链接的仓库和文件夹不变
- **且** 生成的技能应限定在工作区规划目录范围内

#### 场景：非交互式设置工具选择
- **当** 非交互式工作区设置收到 `--tools all`、`--tools none` 或 `--tools <ids>`
- **则** OpenSpec 应使用选中的工具集进行工作区代理技能安装
- **且** 它应使用与仓库初始化技能生成相同的受支持工具 ID 验证工具 ID

#### 场景：非交互式设置无工具选择
- **当** 非交互式工作区设置省略 `--tools`
- **则** OpenSpec 应在不安装代理技能的情况下创建工作区
- **且** 它应报告未安装工作区技能
- **且** 它应告知用户稍后运行 `openspec workspace update --tools <ids>` 来安装技能

#### 场景：在 JSON 输出中报告设置技能
- **当** 非交互式工作区设置安装代理技能且 JSON 输出已启用
- **则** OpenSpec 应在机器可读输出中包含已生成、已刷新、已跳过或失败的技能安装结果

### 需求：工作区更新管理代理技能
OpenSpec 应提供一个工作区更新流程，用于在设置后刷新代理技能。

#### 场景：更新当前工作区
- **给定** 命令从 OpenSpec 工作区内部运行
- **当** 用户运行 `openspec workspace update`
- **则** OpenSpec 应更新该当前工作区

#### 场景：更新命名的工作区
- **给定** 名为 `platform` 的工作区在本地已知
- **当** 用户运行 `openspec workspace update platform`
- **则** OpenSpec 应更新 `platform` 工作区

#### 场景：通过标志更新工作区
- **给定** 名为 `platform` 的工作区在本地已知
- **当** 用户运行 `openspec workspace update --workspace platform`
- **则** OpenSpec 应更新 `platform` 工作区

#### 场景：更新选中的工作区技能
- **当** 工作区更新完成且选中了代理
- **则** OpenSpec 应为选中的代理刷新 OpenSpec 技能
- **且** 它应为新选中的代理添加技能
- **且** 它应移除不再选中的代理的 OpenSpec 管理工作流技能目录
- **且** 它应更新存储的工作区本地选中代理列表

#### 场景：更新 profile 选择的工作流
- **给定** 全局配置解析为工作流 profile
- **当** 工作区更新刷新工作区本地技能
- **则** OpenSpec 应将工作区本地技能工作流集同步到该 profile 选择的工作流
- **且** 仅当它们是已知的 OpenSpec 管理工作流技能目录时，才应移除取消选择的工作流技能目录
- **且** 它应更新用于漂移检测的最后应用的工作流 ID

#### 场景：工作区更新忽略命令交付
- **给定** 全局配置交付为 `commands` 或 `both`
- **当** 工作区更新刷新工作区本地技能
- **则** OpenSpec 仍应仅更新工作区本地技能
- **且** 它不应生成斜杠命令文件或全局命令文件

#### 场景：仅移除受管理的技能目录
- **当** 工作区更新为未选中的代理移除技能
- **则** OpenSpec 应仅移除已知的 OpenSpec 管理工作流技能目录
- **且** 它应保留代理目录中的不相关文件

#### 场景：通过标志更新存储的代理选择
- **当** 工作区更新收到 `--tools <ids>` 或 `--tools none`
- **则** OpenSpec 应将存储的工作区本地选中代理列表替换为该选择
- **且** 未来不带 `--tools` 的工作区更新应使用存储的选择

#### 场景：非交互式更新工具选择
- **当** 工作区更新收到 `--tools all`、`--tools none` 或 `--tools <ids>`
- **则** OpenSpec 应使用该选中的工具集更新工作区代理技能
- **且** 它应避免提示代理选择

#### 场景：非交互式更新无工具选择
- **给定** 工作区本地选中的代理已存储
- **当** 非交互式工作区更新省略 `--tools`
- **则** OpenSpec 应使用活跃的全局 profile 刷新存储的选中代理
- **且** 它应避免提示代理选择

#### 场景：非交互式更新无存储的选择
- **给定** 未存储工作区本地选中的代理
- **当** 非交互式工作区更新省略 `--tools`
- **则** OpenSpec 应在不安装代理技能的情况下完成
- **且** 它应报告无操作，并指导传递 `--tools`

#### 场景：报告工作区技能漂移
- **给定** 工作区本地技能状态记录了最后应用的工作流 ID
- **且** 活跃的全局 profile 解析为不同的工作流集
- **当** OpenSpec 报告工作区技能状态
- **则** 它应报告工作区本地技能与全局 profile 不同步
- **且** 它应建议 `openspec workspace update`

#### 场景：报告工作区技能同步正常
- **给定** 工作区本地技能状态与活跃的全局 profile 和选中的代理匹配
- **当** OpenSpec 报告工作区技能状态
- **则** 它不应报告 profile 漂移

#### 场景：报告工作区技能更新结果
- **当** 工作区更新更改代理技能状态
- **则** OpenSpec 应报告哪些代理被刷新、添加、移除、跳过或失败

#### 场景：在 JSON 输出中报告工作区更新结果
- **当** 工作区更新使用 JSON 输出运行
- **则** OpenSpec 应在机器可读输出中包含已刷新、已添加、已移除、已跳过或失败的技能结果

### 需求：工作区技能更新表面已记录
OpenSpec 应在面向用户的命令表面中暴露工作区技能设置/更新行为。

#### 场景：工作区更新出现在帮助中
- **当** 用户运行 `openspec workspace --help`
- **则** OpenSpec 应列出 `workspace update`
- **且** 它应将其描述为刷新工作区本地代理技能

#### 场景：工作区更新选项出现在帮助中
- **当** 用户运行 `openspec workspace update --help`
- **则** OpenSpec 应记录工作区选择选项
- **且** 它应记录 `--tools all|none|<ids>`
- **且** 它应说明全局 profile 选择工作流而 `--tools` 选择代理

#### 场景：工作区更新出现在补全中
- **当** 生成 shell 补全时
- **则** 工作区命令注册表应包含 `workspace update`
- **且** 它应包含相关选项，如 `--workspace`、`--tools`、`--json` 和 `--no-interactive`
