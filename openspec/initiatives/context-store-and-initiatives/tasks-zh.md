# 上下文存储与计划方案任务

本文件追踪该计划方案的路线图执行情况。路线图项位于 `roadmap.md` 中；详细工作记录位于 `work-items/` 下。

## 当前 Beta 优先级

在手动 Beta 验证通过后，优先处理新用户在入门过程中遇到的问题，然后再进行更深层次的模型工作：

1. 完成项目 11 的观察记录，足以让后续实现有据可依。
2. 项目 12：无参上下文存储设置、路径安全性和清理。
3. 项目 13："你的代理的下一步"输出、直接 JSON 路径、以及基础指导和交付优化。
4. 项目 14：更新 Beta 指南，使其与改进后的首次运行流程匹配。
5. 项目 15：上下文存储项目根目录和基于模式的稀疏计划方案。
6. 项目 16-18：将升级体验、团队强化和计划方案托管的目标绑定变更推迟到入门路径感觉合理之后。
7. 项目 19：在工作空间行为变为公开/稳定之前，在临近结束时审查 Beta 工作空间兼容性。
