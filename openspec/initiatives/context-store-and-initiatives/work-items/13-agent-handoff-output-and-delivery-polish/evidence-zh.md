# Agent 交接输出和交付优化证据

## 手动 Beta 测试来源记录

手动 Beta 测试发现：

- 上下文存储设置后，用户被告知让 Agent 创建倡议，但新 Agent 可能不了解 Beta CLI 或在哪里找到操作手册；
- `initiative create --json` 报告 `created_files` 为相对名称，因此 Agent 必须在写入前将它们与返回的根路径组合；
- "仅命令"可能听起来像"Agent 得不到任何 OpenSpec 指导"，即使用户可能仅指将斜杠命令作为 workflow 入点；
- 没有命令适配器的工具需要在无法安装 workflow 斜杠命令时得到清晰警告。

## 初始建议

将其视为输出优化，而不是新的 workflow 引擎：

- 添加直接路径字段，而不是破坏现有的相对路径字段；
- 保持交接指导具体且命令级别；
- 将基础 OpenSpec 素养与 workflow 入点分开；
- 将更广泛的"下一步应该做什么？"命令留给提议的交接工作项。
