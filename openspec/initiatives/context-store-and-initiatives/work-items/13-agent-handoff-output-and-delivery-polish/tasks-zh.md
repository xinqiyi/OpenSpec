# Agent 交接输出和交付优化任务

- [ ] 决定哪些现有命令应打印"为你的 Agent 准备的下一步"交接块。
- [ ] 为上下文存储设置、倡议创建、工作区打开和仓库本地关联变更创建定义最小的交接内容。
- [ ] 添加直接的创建路径字段，例如 `created_paths`，在 JSON 输出目前强制 Agent 将相对文件名与返回的根路径组合的地方。
- [ ] 保留现有相对 `created_files` 字段的兼容性，因为调用方可能已依赖它们。
- [ ] 更新 `initiative create --json` 和第 15 项中的稀疏倡议创建输出，以包含直接产物路径和下一步命令。
- [ ] 决定生成的文档或设置输出如何指向 Agent CLI 操作手册，而无需在每个指南步骤中粘贴微型操作手册。
- [ ] 澄清交付术语，使面向命令的交付意味着工作流命令作为入口点，而不是缺乏基础 OpenSpec 指导。
- [ ] 当选中的工具不支持工作流斜杠命令交付时添加警告。
- [ ] 定义为仍支持技能的工具选择面向命令的交付时，如何报告基础 OpenSpec 指导。
- [ ] 为人类输出、JSON 输出和交付警告行为添加测试或 fixtures。
- [ ] 使用优化的交接和交付语言更新 Beta 文档和生成的 Agent 指导。
